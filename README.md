# Анализ продаж Olist в Excel

## О проекте

Проект представляет собой автоматизированную аналитическую систему для анализа данных бразильской e-commerce платформы Olist.

Основная цель проекта — показать возможности Excel как инструмента полного аналитического цикла: от загрузки и подготовки исходных данных до построения модели данных, расчёта показателей, визуализации результатов и автоматизации регулярной отчётности.

Для подготовки данных используется Power Query, для расчётов и анализа — Excel и Power Pivot, а VBA применяется для автоматизации работы с отчётом.

## Цели проекта

Создать в Excel интерактивный аналитический отчёт, позволяющий:

* анализировать динамику продаж и заказов;
* контролировать основные коммерческие показатели;
* определять наиболее значимые товарные категории;
* анализировать сроки выполнения заказов;
* исследовать связь между доставкой и оценками покупателей;
* автоматически обновлять отчёт при изменении исходных данных;
* экспортировать готовый дашборд.

## Данные

В проекте используется открытый датасет [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data).

Для анализа используются следующие таблицы:

* Orders;
* Order items;
* Products;
* Customers;
* Reviews;
* Category translation.

Исходные данные представлены в нескольких связанных CSV-файлах.

## Используемые инструменты

* Microsoft Excel
* Power Query
* Power Pivot
* DAX
* Pivot Tables
* VBA

## Подготовка данных

Подготовка исходных данных выполняется в Power Query.

Основные этапы:

1. Загрузка CSV-файлов.
2. Проверка типов данных.
3. Обработка пропущенных значений.
4. Объединение связанных таблиц.
5. Добавление необходимых расчётных признаков.
6. Подготовка таблиц для загрузки в модель данных.

Для товарных категорий используется отдельный справочник перевода названий с португальского на английский язык.

## Модель данных

Для анализа используется связанная модель данных.

Основные сущности:

* Заказы (Orders)
* Позиции заказов (Order items)
* Товары (Products)
* Клиенты (Customers)
* Отзывы (Reviews)

Связи между таблицами строятся по идентификаторам заказов, клиентов и товаров.

Расчёт бизнес-показателей выполняется с использованием мер Power Pivot / DAX.

## Основные показатели

На дашборде представлены:

* выручка;
* количество заказов;
* средний чек;
* количество проданных товаров;
* средняя оценка покупателей;
* средний срок доставки;
* доля заказов, доставленных с опозданием.

## Анализ

В рамках проекта рассматриваются следующие вопросы:

### Динамика продаж

* Как изменялись продажи во времени?
* Какие периоды характеризуются максимальным ростом или снижением?
* Как меняется количество заказов и средний чек?

### Товарные категории

* Какие категории формируют основную часть выручки?
* Какие категории являются лидерами по количеству заказов?
* Насколько продажи концентрируются в ограниченном числе категорий?

### Выполнение заказов

* Каков средний срок доставки?
* Какая доля заказов доставляется позже ожидаемой даты?
* Как изменяются показатели доставки во времени?

### Оценки покупателей

* Как распределяются оценки заказов?
* Отличаются ли оценки своевременно и несвоевременно доставленных заказов?
* Существует ли связь между сроком доставки и удовлетворённостью покупателей?

## Дашборд

Итоговый дашборд построен непосредственно в Excel и содержит основные KPI, графики и интерактивные фильтры.

Пользователь может фильтровать данные по:

* периоду;
* товарной категории;
* региону.

В репозитории представлен скриншот итогового дашборда.

## Автоматизация VBA

VBA используется как слой автоматизации аналитического отчёта.

Реализованы следующие функции:

### Обновление отчёта

Кнопка обновляет источники Power Query, модель данных, сводные таблицы и связанные элементы отчёта.

### Сброс фильтров

Макрос автоматически возвращает интерактивные фильтры и срезы дашборда в исходное состояние.

### Экспорт отчёта

Макрос формирует готовую версию дашборда и экспортирует её в PDF.

## Ключевые выводы

Раздел будет заполнен после проведения анализа данных.

Планируется выделить основные наблюдения по:

* динамике продаж;
* структуре товарных категорий;
* срокам доставки;
* пользовательским оценкам;
* взаимосвязи операционных и коммерческих показателей.
