# Анализ продаж и качества доставки Olist в Excel

## О проекте

Проект представляет собой интерактивный аналитический отчёт в Excel для анализа коммерческих показателей и качества выполнения заказов бразильского маркетплейса Olist.

Основная задача — построить в Excel единый аналитический инструмент, который позволяет:

- отслеживать динамику продаж и заказов;
- анализировать структуру GMV по товарным категориям;
- контролировать сроки доставки;
- оценивать долю просроченных заказов;
- исследовать связь качества выполнения заказа с оценками покупателей.

Проект выполнен на связанных таблицах исходного датасета с использованием Power Query, Power Pivot, DAX и Excel Dashboard.

Текущая версия является MVP. На следующем этапе планируется добавить VBA-автоматизацию обновления и эксплуатации отчёта.

---

## Бизнес-задача

Предполагаемый пользователь отчёта — руководитель e-commerce / коммерческого или операционного направления.

Отчёт должен отвечать на четыре основных вопроса:

1. Как меняются GMV и количество заказов?
2. Какие товарные категории формируют основной GMV?
3. Как различается клиентская оценка в зависимости от результата выполнения заказа?
4. Как меняются качество доставки и оценки покупателей во времени?

## Данные

Использован открытый датасет **Brazilian E-Commerce Public Dataset by Olist**.

В аналитическую модель включены:

- `Orders` — заказы и даты выполнения;
- `Order Items` — товарные позиции и стоимость товаров;
- `Products` — товары и товарные категории;
- `Customers` — покупатели и география;
- `Reviews` — оценки покупателей;
- `Category Translation` — перевод названий товарных категорий.

В MVP не используются:

- Payments;
- Sellers;
- Geolocation.

### Аналитический период

Для анализа динамики используется период:

**январь 2017 — август 2018**

Неполные граничные периоды сохранены в исходных данных, но исключены из дашборда с помощью отдельного признака аналитического периода в календарной таблице.

## Подготовка данных

Исходные CSV-файлы загружаются и преобразуются в Power Query.

Основные этапы подготовки:

1. Проверка структуры таблиц и гранулярности данных.
2. Назначение корректных типов данных.
3. Проверка ключей, NULL и дубликатов.
4. Удаление неиспользуемых в MVP столбцов.
5. Объединение товаров со справочником перевода категорий.
6. Создание календарной таблицы.
7. Создание расчётных признаков доставки.
8. Подготовка отдельной таблицы отзывов уровня заказа.

## Особенности качества данных

### Несколько отзывов на один заказ

В исходной таблице Reviews содержится:

- 99 224 записей отзывов;
- 98 673 уникальных `order_id`.

Для части заказов присутствует несколько последовательных отзывов.

Чтобы один проблемный заказ не получал повышенный вес при расчёте средней оценки, была создана отдельная таблица `Reviews_OrderLevel`.

Для каждого заказа сохраняется последний отзыв по `review_answer_timestamp`.

После преобразования:

- 1 строка = 1 заказ;
- `order_id` уникален.

### Отсутствующие товарные категории

У 610 товаров отсутствовала исходная товарная категория.

Такие записи не удалялись. Для аналитического представления они объединены в группу **«Без категории»**.

На товары без категории приходится только **1,36% GMV**, поэтому они не оказывают существенного влияния на анализ крупнейших категорий.

### Отсутствующие даты доставки

Заказы без `order_delivered_customer_date` не классифицируются как доставленные вовремя или с опозданием.

Они исключаются из расчёта доли просроченных доставок.

Также обнаружено небольшое количество записей со статусом `delivered`, но без фактической даты доставки. Исходные значения не восстанавливались искусственно.

## Модель данных

Вместо объединения всех источников в одну плоскую таблицу используется реляционная модель данных.

Основные связи:

```text
Customers
    |
    | customer_id
    v
Orders
    |
    | order_id
    +----------------------+
    |                      |
    v                      v
Order Items            Reviews_OrderLevel
    ^
    |
    | product_id
Products

Calendar
    |
    | Date
    v
Orders
```

Такой подход позволяет сохранить исходную гранулярность сущностей и избежать дублирования показателей при объединении таблиц.

## Основные показатели
### GMV

GMV (Gross Merchandise Value) — суммарная стоимость товарных позиций:

SUM(Order Items[price])

Стоимость доставки в GMV не включается.

Показатель не интерпретируется как выручка самого Olist, поскольку датасет не содержит информацию о комиссии маркетплейса.

### Количество заказов

Основной коммерческий показатель количества заказов рассчитывается как число уникальных order_id, присутствующих в Order Items.

### Средний чек
GMV / количество заказов

### Средний срок доставки

Количество дней между датой оформления заказа и фактической датой доставки.

### Доля просроченных доставок
Просроченные заказы
/
Заказы с известной фактической датой доставки

### Средняя оценка

Средний review_score по таблице отзывов уровня заказа, где для каждого заказа используется последний доступный отзыв.

## Dashboard

Дашборд содержит шесть основных KPI:

* GMV;
* количество заказов;
* средний чек;
* средний срок доставки;
* доля просроченных доставок;
* средняя оценка покупателей.

Также представлены четыре аналитических блока:

* Как менялись GMV и количество заказов?
Сопоставление коммерческой динамики по месяцам.
* Какие категории формируют наибольший GMV?
TOP-10 товарных категорий по GMV.
* Как различается оценка по результату выполнения заказа?
Сравнение средних пользовательских оценок для своевременно доставленных, просроченных, отменённых и незавершённых заказов.
* Как менялись доля просрочек и средняя оценка?
Совместная динамика операционного показателя и клиентской оценки.

Дашборд позволяет фильтровать показатели по месяцу внутри выбранного аналитического периода.

## Ключевые результаты
### Коммерческая динамика

За аналитический период общий GMV составил около:

**R$ 13,59 млн**

Основной коммерческий набор данных включает:

**98 353 заказа**

Средний чек:

**R$ 137,68**

GMV и количество заказов имеют сходную динамику: рост и снижение показателей в основном происходят одновременно.

В ноябре 2017 года наблюдается локальный максимум, после которого следует снижение в декабре. С начала 2018 года GMV находится на заметно более высоком уровне по сравнению с большей частью 2017 года.

Выраженная сезонность GMV и количества заказов визуально не подтверждается. Период наблюдения недостаточен для уверенного вывода о годовой сезонности.

### Статусы заказов

За январь 2017 — август 2018 в таблице Orders зарегистрировано:

99 092 заказа

Из них:

97,0% имеют статус delivered;
1,11% — shipped;
0,61% — unavailable;
0,59% — canceled.

Доставленные заказы формируют 97,28% GMV.

Поэтому в качестве основного коммерческого показателя используется общий GMV: недоставленные заказы имеют небольшой вес как по количеству, так и по стоимости.

### Товарные категории

TOP-10 товарных категорий формируют:

62,41% общего GMV

Крупнейшие категории:

`health_beauty` — 9,26% GMV;
`watches_gifts` — 8,87%;
`bed_bath_table` — 7,65%.

При этом ни одна категория не формирует более 10% GMV.

Это означает, что продажи заметно концентрируются в группе крупных категорий, но выраженной зависимости от одной товарной категории нет.

Также заметно различие между рейтингом категорий по GMV и по количеству заказов.

Например, `bed_bath_table` имеет больше заказов и товарных позиций, чем `watches_gifts`, но уступает ей по GMV. Это указывает на различия в стоимости товаров между категориями.

### Качество доставки

Для заказов с известной фактической датой доставки:

**91,87%** доставлены вовремя;
**8,13%** — с опозданием.

Средний срок своевременной доставки:

**10,8 дня**

Средний срок просроченной доставки:

**31,46 дня**

Просроченная доставка занимает почти в три раза больше времени.

### Доставка и клиентская оценка

Средняя оценка своевременно доставленных заказов:

**4,29**

Средняя оценка просроченных заказов:

**2,57**

Таким образом, заказы, доставленные с опозданием, имеют существенно более низкие оценки покупателей.

Результат показывает выраженную связь между соблюдением ожидаемого срока доставки и пользовательской оценкой.

При этом анализ не интерпретируется как доказательство причинно-следственной зависимости: на оценку клиента могут влиять и другие факторы.

### Динамика качества доставки

Наиболее проблемный период наблюдается в конце 2017 — начале 2018 года.

В марте 2018 года доля просроченных доставок достигла:

**21,4%**

В том же месяце средняя пользовательская оценка снизилась до:

**3,75**

После марта 2018 года операционные показатели заметно улучшились.

Средний срок доставки снизился до:

**7,66** дня в августе 2018 года

Средняя оценка восстановилась до:

**4,26**

На агрегированном уровне периоды высокой доли просроченных заказов часто совпадают с более низкой средней оценкой покупателей.

## Что демонстрирует проект

Проект показывает практическое использование Excel для полного аналитического цикла:

* изучение структуры связанных данных;
* понимание гранулярности и ключей;
* проверка качества данных;
* подготовка данных в Power Query;
* построение реляционной модели;
* разработка DAX-мер;
* формирование бизнес-KPI;
* построение интерактивного Excel-dashboard;
* анализ коммерческих и операционных показателей;
* формулирование выводов с учётом ограничений данных.

## Структура Excel-файла
```
00_Управление
01_Дашборд
02_Анализ
03_Доставка
04_Категории
05_Проверка_данных
98_Технические_таблицы
99_Справочники
```

`01_Дашборд` — итоговый аналитический экран.

`02_Анализ` — динамика коммерческих показателей и статусы заказов.

`03_Доставка` — анализ сроков доставки, просрочек и оценок.

`04_Категории` — анализ структуры GMV по товарным категориям.

`05_Проверка_данных` — результаты первичного Data Quality Check.

`98_Технические_таблицы` - сводные таблицы для дашборда.

`99_Справочники` — паспорт источников, определения показателей и техническая документация.

## Ограничения анализа
* Датасет охватывает ограниченный период, поэтому выводы о сезонности требуют осторожности.
* GMV отражает стоимость проданных товаров и не является выручкой самого маркетплейса.
* Датасет не содержит достаточной информации для анализа прибыли или маржинальности.
* Связь между сроками доставки и оценками является наблюдаемой зависимостью, но не доказанной причинностью.
* Анализ категорий ограничен качеством исходной классификации товаров.
